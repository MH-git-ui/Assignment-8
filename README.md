# Assignment-8


## Development

Next.js App Router skeleton with TypeScript, Tailwind CSS, and ESLint.
Design implementation will begin after the Figma design is confirmed.

Requires Node.js 20.9 or newer and pnpm 11.25.0.

```sh
pnpm install
pnpm dev
```

Open http://localhost:3000.

```sh
pnpm lint
pnpm typecheck
pnpm build
pnpm start
```

Edit `src/app/page.tsx` for the home page, `src/app/layout.tsx` for the
shared layout, and `src/app/globals.css` for global styles.
